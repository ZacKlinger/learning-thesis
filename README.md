# learning-thesis

Working repo for an essay arguing the optimistic case for AI/tech in education — specifically that it should enable ambitious learning that wasn't previously possible, while protecting teacher agency.

Mastery first, essay second. The bulk of this repo is the research substrate: a layered canon of learning sciences literature, a claim-evidence ledger, and a weekly digest of advances.

**Explore it:** the [research map](https://zacklinger.github.io/learning-thesis/) draws the whole substrate as an interactive graph of thesis seeds, claim-evidence threads, verified sources, and leads.

## How to read this repo

- **[`digests/`](digests/)**: the weekly digest, written for the human reader. Start with the newest.
- **[`claim-evidence/`](claim-evidence/)**: one ledger per thesis thread (augmentation not efficiency, teacher agency, tech cycles in education, ambition over complacency), each claim tied to a verified quote and locator.
- **[`canon-map.md`](canon-map.md)**: the layered canon of literature the threads draw on.
- **[`leads/`](leads/)**: sources named but not yet read first-hand.
- **[`steers/`](steers/)**: dated, human-written course corrections; when two conflict, the newer one wins.
- **[`sessions/`](sessions/)**: a log of what each research session read and changed.

## Sibling corpus

[`pbl-corpus`](https://github.com/ZacKlinger/pbl-corpus) catalogs project-based learning as a field, disagreements included. Whether PBL counts as the ambitious learning this thesis argues for is decided here. The two repos share one corpus protocol so claims can be ranked across both.

See [`CLAUDE.md`](CLAUDE.md) for the protocol the research agent follows.
